# Insurance Claims Analytics Dashboard — Tableau

Interactive data visualization project analyzing car insurance claims and presenting key patterns and business insights through a Tableau Story.

## Live Dashboard

🔗 [View the Interactive Tableau Story on Tableau Public](https://public.tableau.com/app/profile/manish.guptaa/viz/DataVisualizationusingTABLEAUProjectonCarClaimInsurance/Story1)

## Project Overview

This data visualization project analyzes 7,647 car insurance records across 21 customer, vehicle & claims-related variables. The analysis explores patterns associated with claim frequency & claim amount & presents the findings through an interactive Tableau Story for management-level decision support.
